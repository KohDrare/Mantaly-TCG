# Mantaly TCG

**MantalyClasseur** — le classeur du set de cartes de la Mantaly Party, édition Guillaume.

👉 **[Ouvrir le classeur](https://kohdrare.github.io/Mantaly-TCG/)**

- Touche une carte pour voir sa fiche (attaques, faiblesse, résistance…), touche-la encore pour la voir en plein écran.
- Sur téléphone, accepte l'accès au mouvement : les cartes brillent quand tu penches l'écran.

Illustrations : Arthur.
